# Contributing

Keep changes focused and describe the affected mission/settings, expected behavior,
and checks performed. Separate offline tests from live gameplay observations.
Preserve the original guest calling convention, object ownership and save compatibility.
Never replace failed work with fabricated success or silently drop visual effects.

Do not submit game assets, ISOs, Xbox executables, lifted game source, disassembly,
shader caches, save files or credentials. Keep upstream attribution with borrowed code.
