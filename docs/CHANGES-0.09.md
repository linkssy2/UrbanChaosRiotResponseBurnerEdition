Burner Edition 0.09 improves performance, aiming, co-op controls and installation. Single-player and local co-op remain together in one package, with matching Windows and experimental Linux/Proton builds.

- **Performance:** reduced repeated work in lighting/particle submission, index assembly, render-state copies, constant uploads and file queries without reducing effects or graphical quality. Includes selected XboxXBERecomp rendering optimizations; gains depend on the scene and hardware.
- **Aiming and recoil:** corrected reticle/scene alignment in single-player and both split-screen views. Fixed excessive firing shake at high frame rates. These reported issues received user confirmation in the preceding test builds.
- **Reticle colors:** choose separate colors for normal aim, enemies, friendly NPCs and pistol spin in Graphics > Reticle settings. Co-op players can save their own colors; Original retains the game's colors.
- **Co-op prompts and menus:** pickup text follows the collecting player; NPC/medic prompts use each player's own view. Fixed Player 2 pause navigation and backing out of the Controller reference screen. Removed the invisible menu triggered by holding X.
- **Health packs:** the pack display hides during conversations and menus, with a compact D-pad Down ×2 icon or the assigned keyboard/mouse keycap. Medic requests work at full health when inventory has room and stock remains; saved tutorial history no longer suppresses the collection hint. Controller users double-tap D-pad Down to heal themselves or hold it near an injured/downed partner to heal or revive them. Keyboard/mouse gets a separate rebindable **Heal Partner** action, default **U** unless already assigned. Treatment spends the giver's pack.
- **Menus and controls:** Co-op sits directly below Single Player, Xbox Live is removed, and Cheats is available from the main menu with the original unlock behavior. Added independent mouse-look inversion.
- **Character selection:** all five rotating co-op character previews now hold a pistol using the game's original hand attachment and pose.
- **Movies:** FMV **Fill** shows the whole movie across the screen, stretching 4:3 material instead of cropping it. **4:3** preserves original proportions. Black bars encoded into the movie itself may remain.
- **Setup:** updated Play/Manage layout with **Use ISO directly**, **Import once**, and **Use Existing Install**. Reuse existing game data, saves, settings and add-ons without copying another installation. A single supported ISO in `assets/` can start first-time setup.
- **Launcher updates:** Windows **Manage > Check for updates** downloads and installs newer official releases, then reopens the launcher. Linux uses `./burner.sh update` with native Python. Downloads are verified and interrupted updates can roll back; saves, settings, ISOs and installed add-ons are kept.
- **Optional diagnostics:** enable **Manage > Diagnostic Logging** before reproducing a problem, then use **Open Logs**. Logging is off by default, bounded and local, with no automatic uploads. Includes setup errors, runtime/system/settings details and FPS samples; Windows and Proton use the same setting.
- **Linux setup:** retain one Steam shortcut for setup and play. The terminal launcher now resolves shortcuts to its real package and gives clearer failure guidance. Native Linux launcher checks pass; this is still a Proton package, not a native port.
- **Runtime maintenance:** the current build uses XboxXBERecomp and maintained Urban Chaos adapters; the retired runtime dependency is removed from the active build and new source snapshot.

**Updating:** close the game and launcher, then extract the complete package over the existing folder. Keep `GameData`, `installation.json`, external installations, and any directly used ISO. Alternatively, choose **Use Existing Install** in the new launcher. On Linux, keep the same Steam shortcut and its prefix, or `.proton` for the terminal route; update Target and Start In together if the package moves. Follow `README-linux.txt` for Steam setup. Older launchers need this complete package installed once to gain online updates. From 0.09 onward use **Manage > Check for updates** on Windows or `./burner.sh update` on Linux. Linux interpreter-changing updates still require manual package replacement.

**Updated HD textures:** a new separate **0.09 HD Game Textures ZIP** adds **565 texture mappings**, bringing coverage to **1,803 mappings / 1,800 replacement files**. Includes more environment, character, weapon and effects artwork; no menus or HUD. Close the game and install the ZIP through **Manage > Install HD Texture Pack** on Windows, or the texture-pack steps in `README-linux.txt`. The same ZIP serves both platforms. Install it to get the new coverage; updating the game alone keeps your existing pack. The 0.06 pack remains compatible.

**Spanish:** HD HUD artwork and Spanish text remain bundled in the main game package. Optional Spanish voices are imported locally from your European PS2 ISO; no game-audio download is distributed.

**Remaining limits:** the expanded HD pack passed source and installation checks but still needs in-game visual acceptance on both platforms. Co-op remains experimental, with incomplete campaign/character/turret coverage. HD HUD prompt/display issues, the intermittent missing injured officer in Angel Heights, and Spanish voice/text review remain outstanding. The medic prompt has user confirmation. Windows menu checks passed for reticle color selection, all five pistol-holding character previews, co-op setup and difficulty navigation; gameplay reticle colors and controller healing still need live acceptance in this candidate. This exact build has not received Linux/Proton gameplay verification. The source ZIP is for inspection/contribution; a complete build from a fresh checkout is not yet supported.
