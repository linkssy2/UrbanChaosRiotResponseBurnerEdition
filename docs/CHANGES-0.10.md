# Burner Edition 0.10 changes

**Audio and high-FPS fixes, with new control options.**

- Added Stereo, 5.1 Surround and 7.1 Surround output choices, with fallback for unsupported devices.
- Added per-player zoom sensitivity. Regular and zoom sensitivity now use percentages, with defaults shown as 100%.
- Added rebindable Walk with Hold/Toggle behavior and Toggle HUD controls. Assign them in Controls; they start unbound.
- Fixed Hold Aim dropping when firing.
- Fixed the first medic's missing health-pack prompt when you have inventory space, including co-op.
- Fixed overly fast NPC blinking and exaggerated ragdoll launches at high FPS, including police gunfire kills.
- Fixed Officer Daniels' placement in Angel Heights, preventing the reported missing-officer rescue failure.

Single-player and co-op remain together. Windows and experimental Linux/Proton use the same updated runtime; this Proton build has not been gameplay-tested. Configure surround speakers in your system first and restart the game after changing the device layout.

**Updating:** use **Manage → Check for Updates** in the launcher once this release is published, or extract the complete new package. Saves, settings and installed add-ons are retained. Spanish text remains integrated. The separate [0.09 HD texture pack](https://github.com/linkssy2/UrbanChaosRiotResponseBurnerEdition/releases/tag/v0.09) is compatible; no reinstall is needed.

HD HUD prompting still needs work; the original HUD remains available. Co-op remains experimental.
