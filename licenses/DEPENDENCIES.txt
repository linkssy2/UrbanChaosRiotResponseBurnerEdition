Current 0.08 runtime and setup tools:

- XboxXBERecomp by TGP482: XboxXBERecomp.txt (MIT), pinned in dependencies.lock.json.
- XboxXBERecomp dependencies: XboxXBERecomp-third-party.txt (Zydis, toml++, Dear ImGui and SDL).
- Retained sp00nznet/xboxrecomp helpers/importer: xboxrecomp.txt, xboxrecomp-notice.txt and LGPL-2.1.txt.
- libusb 1.0.29 (LGPL-2.1-or-later): the binary packages include the unmodified DLL, license and corresponding upstream source archive.
- Embedded Python, OpenSSL and zlib: their unmodified notices accompany the binary packages.
- Microsoft Visual C++ runtime: redistribution notices accompany the binary packages and are maintained in launcher/burner-xbe/.
- FFmpeg 8.1.2 full shared build by www.gyan.dev (GPLv3): FFmpeg-LICENSE.txt and FFmpeg-README.txt contain the license, source and build information. Used as a separate program for local PS2 movie-audio conversion; binaries are included only in the Windows/Proton packages.

Historical source notices:
- Jolt Physics: JoltPhysics.txt (earlier standalone-native work).
