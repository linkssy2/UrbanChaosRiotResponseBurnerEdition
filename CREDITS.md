Python, OpenSSL, zlib, SDL3, Dear ImGui, toml++, libusb and Microsoft Visual C++
runtime notices accompany the binary packages. Optional local PS2 voice conversion
uses the pinned FFmpeg shared Windows tools, with their GPLv3 license and build/source
notices. No original or converted game audio is distributed. Historical source
also retains Jolt Physics and earlier FFmpeg integration; that historical game
runtime is not the current release path.

Launcher artwork was generated for Burner Edition from a local cover reference.
Restored UI artwork is described in `artwork/README.md` and its provenance manifest.
Development used AI assistance. This unofficial fan project is not endorsed by
the original developers or toolchain authors.
