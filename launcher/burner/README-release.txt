Urban Chaos: Riot Response - Burner Edition 0.01

Windows x64 fan port using xboxrecomp and native PC engine components.
Original gameplay and mission logic run through statically recompiled Xbox code.
Includes mouse/keyboard controls, controller support and in-game graphics options.

INSTALL
1. Extract the entire ZIP to a folder.
2. Run Burner Edition Setup.exe and select your supported original Xbox ISO.
3. Once imported, use Play Burner Edition.exe to play without opening setup.
Keep the EXEs, tools, runtime and shaders folders together.

PERFORMANCE
Dynamic scenery lighting and character lighting can cause slowdowns, especially
with multiple characters or effects. Lower Character lighting quality or disable
these lighting options in Graphics, then press Apply. Stable 60 FPS is not guaranteed.
Routine runtime logging and diagnostic recorders are disabled in this build.

DATA
No original disc image, game assets, videos or saves are included.
Import, settings and saves remain in %LOCALAPPDATA%\UrbanChaosBurnerEdition.
Existing installations are reused. Create a new in-game profile for fresh progress.
Only the supported disc revision is accepted. Windows x64 and a D3D11-capable GPU
are required. If the game exits unexpectedly, last-error.txt is saved in that folder.
