URBAN CHAOS: RIOT RESPONSE - YOUR XBOX DISC IMAGE

Place ONE supported original Xbox ISO or XISO in this assets folder, then open
Burner Edition Setup.exe or Play Burner Edition.exe. On Linux/Proton, use the
normal Steam launch command in README-linux.txt.

With no installation selected, setup verifies the image and prepares the files
the port needs. Original game files are read from the ISO during play. Keep the
ISO here for future launches and updates; the source image is never modified.

Existing installations take priority. Dropping in an ISO will not replace one.
If more than one image is here, choose it explicitly with SELECT GAME > USE ISO
DIRECTLY. To copy the game once and remove the ISO afterward, choose IMPORT ONCE.
USE EXISTING INSTALL reuses an older package or GameData without duplicating it.
If an ISO used directly moves, select its new location with USE ISO DIRECTLY.

Extract ISO/XISO files from ZIP/RAR archives before selecting them. Renaming a
different game or unsupported revision does not make it compatible. No game
disc image or other original game payload is included with this package.

See README.txt for Windows setup and README-linux.txt for Linux/Proton commands.
